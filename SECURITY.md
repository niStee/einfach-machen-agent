# Security Policy

## Reporting a Vulnerability

We take the security of `einfach-machen-agent` seriously. If you discover a security vulnerability, please report it responsibly:

- **Do NOT** open a public GitHub Issue for security vulnerabilities.
- Send an email to the repository maintainer or use GitHub Private Vulnerability Reporting under the **Security** tab.

## Security Audit & Safeguards

This repository automatically enforces OpenSSF Scorecard compliance:
- 🛡️ Automated secret scanning via Gitleaks
- 🔒 Branch protection and mandatory CI status checks
- 📦 Weekly dependency updates via Dependabot
- 🧪 Multi-step dry-run submission safeguards
